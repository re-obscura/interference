# interference · сайт

Статика для GitHub Pages: `index.html`, `css/`, `js/`, `fonts/`, `img/`.
Без сборки — просто откройте `index.html` или опубликуйте содержимое папки
в репозитории с включённым Pages.

Сайт — порт главного меню и экрана загрузки игры: те же фоновые сцены
(Лоренц, филлотаксис, тор, сфера π, тессеракт, торус-узел, Жюлиа), золотая
спираль с бегущей точкой, CRT-слои (зерно, скан-линии, мерцание, глитч)
и шрифт DotGothic16.

## Что заменить перед публикацией

- **Донаты** — `index.html`, секция `#support`: href у кнопки и трёх карточек.
- **Контакты** — `index.html`, секция `#contacts`: адреса почты, телеграм,
  github, itch.io (и `data-copy` у кнопки копирования).
- **Тексты дорожной карты** — `js/main.js`, массив `ROADMAP` (статусы
  `ok` / `now` / `plan`, `since` — дата старта активного шага, `frac` — его
  готовность 0…1; проценты и фигуры пересчитаются сами).
- **Прогресс систем** — `js/main.js`, массив `SYS`.
- **og:image** — абсолютный URL в `index.html` после появления домена.

## Шрифты

DotGothic16, VT323, Pixelify Sans — SIL OFL 1.1, лицензии в `fonts/OFL-*.txt`.
Файлы `.woff2` — субсеты (кириллица, латиница, πΣ∫φΔ), собраны из TTF игры.
